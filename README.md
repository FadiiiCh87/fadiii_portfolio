# Muhammad Fahad — Engineering Portfolio

A responsive, multi-page portfolio implementation following the supplied Google Stitch design:
- Dark-mode-first "Technical Elegance" visual system
- Inter + JetBrains Mono typography
- Electric blue → violet accent gradient
- Technical grid/border motifs
- Circular professional portrait
- Responsive mobile navigation
- Home, Services, Laundry ERP Case Study, and Experience pages
- Client-side contact form that opens the visitor's email client

## Files

- `index.html` — main portfolio
- `services.html` — engineering services
- `laundry-erp.html` — Laundry Management ERP case study
- `experience.html` — experience, capabilities, education/certifications
- `styles.css` — shared design system and responsive styles
- `script.js` — mobile menu + contact form behavior
- `assets/profile.png` — portrait supplied in the Stitch package

## Run

No build tools are required.

Open `index.html` directly in a browser, or use VS Code Live Server.

## Before publishing

1. Replace `your-email@example.com` in `index.html` and `script.js` with the real portfolio email.
2. Add the real PDF as `assets/Muhammad-Fahad-Resume.pdf` and change the Resume link if you want direct PDF download.
3. Verify GitHub and LinkedIn URLs.
4. Deploy the folder to GitHub Pages, Netlify, Vercel, or any static host.

The implementation intentionally uses plain HTML/CSS/JS so it is easy to maintain in VS Code and deploy without a framework build step.
